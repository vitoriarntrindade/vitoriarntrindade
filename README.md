## 🤘 Sobre mim

Olá, pequeno gafanhoto! 🦗

Eu sou a **Vitória**, engenheira de plataforma e desenvolvedora Python movida a **café forte, curiosidade e rock no fone** — provavelmente com System of a Down tocando enquanto o terminal está aberto. 🎶

Minha jornada em tecnologia começou em 2023 e, desde então, venho trabalhando entre **engenharia de software, backend, dados, cloud e automação**, construindo soluções que resolvem problemas reais e tornam processos mais confiáveis, escaláveis e menos manuais.

Hoje atuo como **Platform Engineer no Itaú Unibanco**, trabalhando na sustentação e evolução de uma plataforma interna de autosserviço para disponibilização de dados utilizados em cenários de testes.

No dia a dia, tenho contato com:

* ☁️ **AWS**, principalmente Lambda, API Gateway, EC2, CloudWatch e serviços serverless
* 🔗 Desenvolvimento, integração e modernização de **APIs**
* 🐍 Desenvolvimento de soluções e automações com **Python**
* 🧩 Manutenção e evolução de aplicações legadas em **.NET**
* 🧪 **Testes unitários**, qualidade de código e pipelines de **CI/CD**
* 🛢️ Bancos relacionais como **PostgreSQL, MySQL e SQL Server**
* 🤖 Uso de **IA aplicada ao desenvolvimento**, com ferramentas como GitHub Copilot e Devin

Antes disso, também atuei fortemente com **Data Engineering**, desenvolvendo pipelines ETL, automações, APIs, soluções de web scraping e processamento de dados em ambientes AWS e Azure.

Já construí soluções envolvendo:

* ⚙️ Pipelines ETL com **AWS Step Functions e Lambda**
* 📊 Processamento e qualidade de dados com **Pandas e Polars**
* 🔎 Web scraping e automação com **Playwright e Selenium**
* 🚀 APIs REST com **FastAPI e Django**
* 🧠 Soluções de **RAG e Generative AI com AWS Bedrock**
* ☁️ Arquiteturas e integrações utilizando **AWS e Azure**
* 🔄 Automação de processos e integrações entre diferentes sistemas

Gosto de entender o **porquê das coisas**, escrever código que outras pessoas consigam entender e explorar maneiras de usar tecnologia para eliminar trabalho repetitivo.
